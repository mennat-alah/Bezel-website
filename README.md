# Bezel — Creative Agency Landing Page

A responsive creative agency landing page built with HTML, CSS, and Bootstrap 5.3. This project focuses on recreating a modern agency website layout while practicing responsive design, interactive UI elements, and custom styling.

## Overview

Bezel is a frontend practice project built to strengthen my HTML, CSS, and Bootstrap skills by recreating a multi-section landing page for a fictional creative agency.

I completed the project in approximately **6 hours**, focusing on implementing the layout, styling the different sections, and making the page responsive.

## Live Demo



## Features

- Responsive navigation bar with a collapsible mobile menu.
- Hero section with a Bootstrap carousel.
- About section introducing the agency.
- Creative team section with image overlays and hover animations.
- Services section presenting the agency's offerings.
- Pricing section with four pricing plans and a highlighted plan.
- Testimonials carousel with custom-styled indicators.
- Contact section with an embedded Google Map and contact form.
- Custom hover effects, transitions, and responsive layouts.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Font Awesome
- Google Fonts

## What I Practiced

- Building responsive layouts using Bootstrap's grid system and utility classes.
- Combining Bootstrap components with custom CSS.
- Creating hover effects and CSS transitions.
- Customizing carousel indicators and controls.
- Using positioning and transforms to achieve specific layouts.
- Applying media queries to improve responsiveness.
- Organizing CSS styles by page section.

## Design Approach

As with my previous practice projects, I used a website associated with Route Academy courses as a visual reference and tried to estimate the spacing, sizing, and positioning by observing the original design.

Since I didn't have a dedicated design file, I relied on visual observation and experimentation to recreate the layout as closely as possible. This gave me more practice translating visual references into code and making styling decisions independently.

## Getting Started

1. Clone this repository.
2. Make sure the CSS, JavaScript, and image assets are included in their respective folders.
3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
